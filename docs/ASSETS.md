# Assets

O APK usa:

- frames WebP selecionados do `Pixel Chest Pack`;
- quatro ficheiros de áudio em `res/raw`.

O APK não inclui spritesheets completos, GIFs ou ZIPs.

Scripts úteis:

```powershell
python tools/analyse_design_sources.py
python tools/build_chest_assets.py
python tools/generate_asset_catalog.py
python tools/audit_pt_pt.py
```
