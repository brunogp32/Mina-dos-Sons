# Contributing

Thank you for helping Mina dos Sons.

- Keep the app offline and child-safe.
- Do not add analytics, adverts, real-money purchases, or network calls.
- Preserve existing progress and DataStore migrations.
- Keep Portuguese text in Portuguese from Portugal.
- Run `.\gradlew.bat testDebugUnitTest lintDebug assembleDebug` before proposing changes.
- Document any new third-party asset in `ASSET_LICENSES.md` and `THIRD_PARTY_NOTICES.md`.
