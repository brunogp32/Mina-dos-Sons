# Segurança

## Versões suportadas

Apenas a versão mais recente publicada em GitHub Releases recebe correções.

## Reportar problemas

Se encontrares um problema de segurança ou privacidade, não publiques gravações, dados de crianças,
keystores, passwords ou tokens numa issue pública. Contacta o proprietário do repositório e inclui apenas:

- versão da aplicação;
- modelo e versão Android, se relevante;
- passos gerais para reproduzir;
- impacto esperado.

## Dados sensíveis

O projeto não deve conter keystores, passwords, tokens, gravações reais de crianças ou ficheiros locais.
As builds de release devem ser assinadas com secrets do GitHub Actions.
